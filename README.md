# AJA Platform — instalatory

Oficjalne instalatory **AJA Platform** (AJA Skrypt i AJA Interkom) od [AJA Studio](https://ajastudio.pl).
To repozytorium zawiera wyłącznie gotowe instalatory w zakładce **Releases** — bez kodu źródłowego.

**Pobieranie:** najwygodniej przez stronę [ajastudio.pl/pobierz](https://ajastudio.pl/pobierz/), która sama
wskaże wersję dla Twojego systemu.

Stałe linki do najnowszej wersji:

| System | Plik |
|---|---|
| macOS 12+ (Apple Silicon i Intel) | [AJA-Platform-macOS.dmg](https://github.com/ajastudiopl/AJA-Platform-downloads/releases/latest/download/AJA-Platform-macOS.dmg) |

Ta sama instalacja służy do wersji próbnej (14 dni, bez rejestracji) i do pracy z kupioną licencją —
klucz wpisujesz w aplikacji: LICENCJA → AKTYWUJ. Licencje: [ajastudio.pl/sklep](https://ajastudio.pl/sklep/).

Sumy kontrolne SHA-256 każdego wydania są w pliku `SHA256SUMS.txt` dołączonym do wydania.
